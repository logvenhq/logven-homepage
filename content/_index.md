question = "What is an executable digital twin?"
answer = "A live, versioned model of your company’s data and processes that actually runs the work. It is built from executed work rather than drawn by hand, so improving the model changes how the work is done."

[[extra.faq]]
question = "How is Logven different from an agent platform?"
answer = "Agent platforms sell agents. For Logven, agents are how the twin gets built. Stable work is hardened into deterministic, traceable code, and language models stay only where real ambiguity remains."

[[extra.faq]]
question = "Can it run on our own infrastructure?"
answer = "Logven is designed for local deployment on customer hardware with smaller models, which also reduces inference cost."

[[extra.faq]]
question = "Who uses Logven day to day?"
answer = "Technical specialists work with the workers the way they would with an assistant. Department heads use the resulting model to see, version and optimise how the department runs."

[[extra.faq]]
question = "What does a pilot involve?"
answer = "A paid pilot on one team’s real workflows and data. From there, the system moves to deployment and an annual licence priced per team, not per employee."

[[extra.faq]]
question = "Can Logven connect to our existing tools?"
answer = "Yes. Custom tool integrations are available as an add-on, as is finetuning of Logven’s models for your domain."
