Every company comes down to two things: what it knows and what it does.

We call the first one state and the second one functions. Put them together and you have a working model of your company.

State

Your data lives in sheets. Every process reads and writes the same copy.

Functions

Each process becomes a function with clear rules. A worker runs it.

The model

You can see which process touches which data and who’s responsible for it.

You start with one task and grow from there.

No long setup or back-and-forth with IT. The data model takes shape from everyday work.

Sheets

Sheets hold your data. They look like a spreadsheet and behave like a database.

Workers

Workers do the job, using your data and your tools.

Boards

Boards turn raw data into live, flexible analysis.

Processes

A process bundles the sheets, workers and boards behind one job.

Every process is written as a program.

How a pilot works

It does what you approved, every single time.

Your team describes the process and Logven drafts a worker. Someone approves it, and from then on it runs the same way every time.

It follows the approved steps.
The same rules run in the same order on every run.
It only sees what it needs.
Each worker gets access to specific data and tools, and nothing else.
Every run leaves a record.
Inputs, outputs and calls to other systems are logged. You can trace any result back to the step that produced it.
Changes need a sign-off.
Every change is a new version, and it can’t run until someone approves it.

Some steps need a model. The worker keeps it on a short leash.

Reading a supplier’s PDF is a good example. The worker asks the model, checks what comes back and decides what to do with it.

A model gets one step.
It never runs the whole process.
Answers get checked.
If an answer comes back in the wrong shape, the worker throws it out.
The rules live in code.
Calculations, business rules and the order of steps are never handed to a model.
Every call is saved.
Each request and its answer are stored with the run.

How Logven compares with custom software and agents

Custom software is dependable, but every change takes months. Agents change in minutes, but you never quite know what they’ll do. Logven gives you the dependability and the speed.
