Custom software

Reliable and slow to change

Where it starts
Weak. It needs a full specification months before anything runs
When the work changes
Weak. Each change is a new project and adds to the maintenance bill
Given the same input twice
Strong. It gives the same output
Checking a result
Partial. It is possible if someone documented the logic
Where it runs
Partial. Wherever it was built to run

Autonomous agents

Flexible and hard to predict

Where it starts
Strong. It starts from a written instruction
When the work changes
Strong. It adapts straight away
Given the same input twice
Weak. It may give a different result
Checking a result
Weak. Its results are hard to reproduce or audit
Where it runs
Partial. Usually on an outside provider’s servers

Logven

Reliable and quick to change

Where it starts
Strong. It starts from the work as your team does it today
When the work changes
Strong. The team describes the change and Logven drafts a new version for review
Given the same input twice
Strong. Rules run the same way each time, and model steps are checked and recorded
Checking a result
Strong. Every step is recorded and can be traced to its source
Where it runs
Strong. On your own infrastructure, with models that run privately
